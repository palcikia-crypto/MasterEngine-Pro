# 🎛 MasterEngine

**Автоматический мастеринг с ML-подбором настроек, веб-панелью и мастерингом каждого стема отдельно.**

Загружаешь трек — движок сам анализирует звук, подбирает цепочку обработки, рендерит и уточняет настройки в замкнутом цикле, пока метрики не сойдутся с целевыми. Открыл панель, нажал A ⇄ B — слушаешь разницу в наушниках.

## Что умеет

- **Полностью автоматический мастеринг** — без ручных настроек (но всё можно покрутить live-слайдерами)
- **ML-слой в два этапа:**
  1. *Предсказание* — фичи трека (LUFS, crest, тон-баланс по 7 полосам, спектральный центр, стерео-ширина) → параметры цепочки через линейную модель + nearest-neighbour по базе ранее обработанных треков (`masterengine/learned_presets.json`) — движок «учится» на каждом треке
  2. *Замкнутое уточнение* — рендер → замер → ошибка к целям (LUFS, crest, тон-баланс) → подстройка параметров → снова, до сходимости
- **Мастеринг по каждой дорожке (stems)** — HPSS-разделение на барабаны / бас / вокал-полосу / остальное, каждая дорожка мастерится отдельно своим пресетом и склеивается обратно. Если поставить `demucs` + `torch` — используется нейросетевое разделение автоматически
- **A/B-слушание в панели** — два синхронных плеера + кнопка A ⇄ B, волна, спектр до/после, метрики LUFS / dBTP / crest / ширина
- **Полная цепочка эффектов:** HPF, 7-полосный EQ, 3-полосный мультибенд-компрессор (LR4), сатурация, эксайтер, де-эссер, стерео-виденер с bass-mono, lookahead-лимитер с гарантией по true-peak
- **Метринг по BS.1770** — K-weighted LUFS с гейтингом, true peak 4x

## 🌐 Веб-панель по ссылке (без установки)

Сайт-панель живёт на GitHub Pages: **https://palcikia-crypto.github.io/MasterEngine/**

Движок — чистый JavaScript (`js-engine.js`), работает прямо в браузере без Python и без загрузки рантаймов: панель готова к работе почти мгновенно. Файлы никуда не отправляются, всё считается локально. Python-версия движка (`masterengine/`) остаётся в репозитории для локального/серверного использования.

Панель — полноценное **PWA**: можно установить как приложение (Android — Chrome «Установить приложение», iOS — Safari «На экран “Домой”»). Service worker кеширует все файлы: панель открывается офлайн и переживает пропажу интернета; обновления подтягиваются автоматически при следующем открытии онлайн.

## Быстрый старт (локально)

```bash
pip install -r requirements.txt
python run.py            # панель: http://127.0.0.1:8000
```

Опционально — нейросетевые стемы:

```bash
pip install torch torchaudio demucs    # двойной вес, но разделение студийного уровня
```

## Проверка движка без браузера

```bash
python test_engine.py    # генерирует демо-трек, мастерит, мастерит стемы, печатает метрики
```

Результат последнего прогона (реальный трек, CC0 — Juhani Junkala «Level 1», фрагмент):

| Метрика | До | После |
|---|---|---|
| LUFS | −6.4 (клип, пережат) | **−14.4** |
| True Peak | +0.8 dBTP | −3.7 dBTP |
| Crest | 8.4 dB | 13.1 dB |

## Целевые настройки по умолчанию

- Громкость: **−14 LUFS** (стандарт стриминга), меняется слайдером в панели (для «громкого» мастера ставь −9 ÷ −8)
- Потолок: **−1.0 dBTP**

## Архитектура

```
masterengine/
├── dsp.py        # ядро DSP: фильтры, кроссоверы, динамика, лимитер, метринг LUFS/TP
├── analysis.py   # экстракция фич для ML-слоя
├── ml.py         # модель настроек + опыт обучения (learned presets) + замкнутое уточнение
├── master.py     # оркестратор: predict → render → refine (closed loop)
├── stems.py      # HPSS/Demucs-разделение и пер-стем мастеринг
├── web.py        # FastAPI: upload / master / audio / peaks
└── static/       # панель: дроп-зона, A/B, спектр, метрики, live-слайдеры
```

## Лицензия на тестовый трек

Проверочный трек в тестах генерируется синтетически. Реальные треки (например, любимый трек ПВЧК) — права принадлежат правообладателям: грузи в панель только те файлы, на которые имеешь право.
